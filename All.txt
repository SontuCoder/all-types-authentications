1. Types of Authentication
No.	Authentication type	Description
1	Basic Authentication	Username and password sent with each request (usually Base64-encoded).
2	Session-Based Authentication	Server creates and maintains a session after login.
3	Token-Based Authentication	Client receives a token and sends it with subsequent requests.
4	JWT Authentication	Uses JSON Web Tokens to verify users without server-side session storage in typical implementations.
5	OAuth 2.0	Allows an application to access resources with delegated authorization.
6	OpenID Connect (OIDC)	Adds an identity layer on top of OAuth 2.0 for user authentication.
7	API Key Authentication	Uses a unique key to identify an application or client.
8	Multi-Factor Authentication (MFA)	Requires two or more authentication factors.
9	Certificate-Based Authentication	Uses digital certificates to verify identity.
10	Biometric Authentication	Uses fingerprints, facial recognition, etc.
